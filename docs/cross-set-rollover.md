# Совместный переход между комплектами · AND-119

Все последние сезоны с одинаковыми UTC cycle_epoch / ends_at образуют обязательную
когорту. Незавершённый совместимый сезон откладывает весь переход; несовместимые
операторские/dev-календари не смешиваются. Лига требует 450 результатов и сверку 18 игр на клуб;
обычный кубок — 49 решённых пар / 97 результатов; общий чемпионский турнир —
все пары и результаты, также для гостевых клубов. Незавершённые товарищеские
тоже блокируют переход. Фактическое окончание всех матчей учитывается при
назначении нового сезона.

Pure allocation формирует отдельные promoted/relegated pools для каждого tier,
по два места от каждого применимого соседнего уровня. Оставшиеся сохраняют
свою лигу; повысившиеся/понизившиеся могут попасть в любой комплект когорты.
Во всех получающих лигах ровно по 10 клубов. Один immutable receipt фиксирует
cohort/seed/назначения; сортировка job не выбирает лигу назначения.

В **одной транзакции** создаются все следующие сезоны, меняются все membership,
возраст/последний сезон/пенсия, бот-замены, заявки, новые sponsorship/cup calendars
и чемпионский отбор из прошлых таблиц. Сбой второго комплекта откатывает первый.
Повтор любого peer job читает свой rollover receipt. Person получает ID сезона
назначения без второго прибавления возраста или нового пенсионного решения;
исторические membership и результаты не переписываются. Глобальные новые
кандидаты и кадровые карьеры создаются после старения всей когорты, чтобы
следующий комплект не обработал нового человека повторно. Контракты, ledger,
лица и общий возрастной бюджет развития сохраняются.

Новые комплекты заранее готовятся в общем календаре: прошедшие матчи
рассчитываются ботами до выдачи клубов. Подготовка также блокирует общий переход,
даже если последний матч этого комплекта уже закончен. Первый worker не выбирает
подмножество готовых peers. [Правила и запас готовых мест](world-reserve.md).
