# Задания внешним агентам · 2026-10-15

## Новая волна — практика матчей и сетка чемпионов

Два самостоятельных задания, можно выдавать параллельно от актуального
origin/main с приёмкой `f1be2e90`. Каждый промпт копируется целиком.
Агенты ещё не запущены. Их выходные файлы не пересекаются.

| Задача | Промпт | Выход |
|---|---|---|
| AND-130 | [Практика за все игровые матчи](and-130-match-practice.md) | Новая чистая policy формы/развития/опыта, 0..120 минут, сниженный friendly progress и калибровка |
| AND-126 | [Сетка готовой группы чемпионов](and-126-champions-bracket.md) | Graph для 8..512 клубов, home/away, neutral final, условные слоты и progression |

[AND-130](https://linear.app/andrei-brazhnikov/issue/AND-130/nachislyat-formu-i-razvitie-za-vse-igrovye-matchi-snizhaya-progress)
включает полное игровое подключение и не закрывается после одного калькулятора.
Точная шкала товарищеских и форма требуют явной калибровки; агент предлагает
вариант, а не объявляет его уже согласованным правилом. Готовая champions group
не заменяет отсутствующую сетку: второй агент продолжает AND-126 после прошлой приёмки.

Общие БД/миграции, pin/apply, match runtime, rollover/jobs, UI и финальная
приёмка остаются у Codex. Новых БД и конкурентных сбросов нет. Самостоятельно
сливать в main или запускать других агентов в этих заданиях не разрешается.
