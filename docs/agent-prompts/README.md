# Задания внешним агентам · 2026-10-15

## Новая волна — готова к выдаче

Промпты самостоятельные: каждый можно скопировать целиком в отдельного агента.
Все три задания разрешено выполнять параллельно от актуального origin/main,
содержащего приёмку `85555275`. Код и тесты разделены по новым файлам.
Агенты этой волны ещё не запущены; родительские задачи не закрываются по одному подпакету.

| Задача | Промпт | Выход |
|---|---|---|
| AND-124 | [Завершение кубковой пары](and-124-knockout-rules.md) | Агрегат, переход к ET/пенальти, победитель по явным результатам |
| AND-126 | [Отбор и группы Кубков чемпионов](and-126-champions-groups.md) | Top 8 по qualifying tier, seeded группы и структурные дни |
| AND-71 | [Аудит игрового баланса](and-71-gameplay-balance.md) | Офлайн-прогоны экономики/скаутинга/роста и отчёт без изменения формул |

AND-124/126 — приоритетные для следующего турнирного этапа. AND-71 не зависит
от их результатов и анализирует только уже работающие правила; будущие кубки
не должны молча включаться в фактические доходы или развитие игроков.

Codex оставляет за собой общую схему БД, durable knockout runtime, rollover,
календарь/jobs, тренировочные резервы, ledger и Telegram UI. Внешние агенты не
запускают сброс единственной БД и не меняют эти файлы. Результат — commit/patch
для приёмки; самостоятельно вливать в main и запускать других агентов не нужно.
