## Практика

League/cup/champions используют одну небольшую шкалу; по фактическим минутам
0..120 рассчитываются навыки, опыт и seeded форма. Общие age-season caps,
потенциал и дроби сохраняются. Для товарищеских предложены отдельные skill и
experience factors по 5000/10000; калибровка сравнивает 25/50/75%. Числа и
односторонняя 0/+1 динамика формы — предложения реализации, не утверждённые
пользователем коэффициенты. Форма 8 в этом предложении не снижается; до включения
нужно оценить долгосрочное насыщение вместе с тренировками и динамикой формы.

Исправлен конкретный дефект: при 0 минут общий grant_growth мог нормализовать
дробь навыка на достигнутом потенциале в 0. Не вышедшему игроку теперь возвращаются
все исходные дроби, навыки, опыт, форма и бюджет. Добавлены регрессии четырёх
соревнований; тавтологический тест `... or True` заменён проверкой переноса дробей.

В калибровке паритет с v1 проверяет growth, experience и experience_gain;
убрана бессодержательная проверка `old == old`. Между тренировками теперь
переносятся мораль/лидерство, ограничен CLI seed. Паритет и воспроизводимость
проверены для seed 0/7/42. Гипотетическое сравнение «товарищеский + тренировка»
не выдаётся за доказанный эффект коэффициента 75%.

Для 18-летнего MC со специалистом 10: 90 официальных минут дают 345 долей
навыка, 120 — 460; товарищеские 90 минут при 50% — 172. Калибровка не выдаёт
доли навыка за целый балл: 10000 долей = 1 балл.

## Сетка чемпионов

Готовая ChampionsGroup на 8..512 участников преобразуется в обычный knockout
graph. Первые пары seeded; дальнейшие связи зафиксированы. Итого N-1 ties,
2N-3 матчей и 5..17 champions cycles, день 2 каждого цикла; финал одиночный
нейтральный, 18-й цикл свободен. Qualification tier/season не пересчитываются.

Усилены проверки отдельных ChampionsTie/ChampionsLeg: раунд, номер leg и цикл
должны соответствовать друг другу до помещения в полный graph. Убрано повторное
сканирование всего списка ties для проверки каждого индекса. В примере финала
используются реальные разрешённые победители обеих ветвей, а не два произвольных
клуба из множества возможных участников. Проверены размеры, повреждённые graphs,
выбывание, одинаковый жребий, ET/пенальти и разделение выручки финала.

Общий тест связывает обе работы: завершённая пара 90+120 минут, один winner
для progression и практика футболиста по двум разным матчам без двойной награды
за основные 90 минут ответного матча. Это pure-сценарий, не PG/runtime-приёмка.
