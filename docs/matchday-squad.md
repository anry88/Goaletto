# Клубный состав и матчевая заявка · AND-95

Клуб по GDD содержит 16–25 футболистов. На матч выбираются XI и до девяти запасных
(11–20 участников). Остальные видны в `/lineup` под «Вне заявки» и продолжают
принадлежать клубу/тренироваться/получать зарплату. Их отсутствие в заявке не означает
продажу, пенсию или потерю внешности.

«Замена» позволяет поставить в XI как запасного, так и игрока вне заявки. При замене
запасным старый участник переходит на его место на скамейке; при замене из резерва —
выходит из заявки. «Скамейка» позволяет исключить запасного, выбрать замену из
резерва или заполнить свободное место до лимита девять. Смена капитана/схемы/тактики
сохраняет невыбранных игроков вне заявки. RU/EN, ownership/version/lineup lock guards
сохраняются; mutable callbacks содержат обе полные UUID и ограниченную версию ≤64B.

Validation проверяет уникальность/принадлежность выбранных игроков, здоровый XI,
одного профильного GK, схему и капитана. Нет требования включать весь roster в матч.
AND-164: дисквалифицированные автоматически заменяются перед lock из существующего
резерва именно для турнира этого матча. При отсутствии здорового профильного GK
из-за дисквалификации допускается аварийный полевой вратарь. [Правила](tournament-discipline.md).
Runtime перед lock проверяет непрерывную нумерацию заявки 1..20 и соответствие
текущему клубу; исходный snapshot содержит только участников заявки. Чистый engine
и его replay формат остаются прежними, максимум20. Исторические snapshots, person/
appearance IDs и банк изображений не меняются. Автозамена травмированного перед
kickoff использует выбранную скамейку.

Проверки: roster25, выбор 21-го/следующих людей из существующих identity, сохранение,
stale revision, healthy/foreign/max guards, полный матч30ticks, bench drop/add через
настоящий callback handler, callback64B при максимально длинной версии, RU/EN.
На единственной development DB выполнены 42 интеграционных сценария; 430 unit tests.
При запуске рынка settlement должен согласованно удалять slot проданного человека,
обновлять version и сохранять валидный XI/bench текущего клуба.
