## Исправления при приёмке

Общий rollover теперь создаёт все новые сезоны заранее и коммитит весь cohort
атомарно. Возраст, пенсионные решения, новый клубный календарь и персонал
используют destination season ID; повтор peer job не проводит второй переход.
Сбой второго комплекта откатывает первый. Совместимость требует одинаковых
cycle_epoch и ends_at; произвольные последние completed сезоны не смешиваются.
Исторические membership, лица, контракты и ledger сохраняются. Новые карьеры
и пополнение глобальных пулов создаются после старения всех исходных сезонов:
иначе ещё не обработанный комплект повторно захватывал людей следующего сезона.

Champions исходно строился только на одном комплекте и не допускал гостей после
перемещения. Общий immutable draw теперь фиксирует отбор из прошлых таблиц всех
комплектов; группы и host plans сохраняются один раз. Гостевой допуск отделён от
фактической лиговой membership, league FK не ослаблены. Календарь, тренировки и
rollover учитывают общую сетку, в том числе для гостей. Посещаемость и сезонный
архив гостя используют его настоящую лиговую membership, а не host season. Реальные 90/120 минут,
ET/pens, нейтральная арена, две доли билетов и практика используют принятый V4.

Товарищеские получили явную accepted booking и проверку подлинного допуска,
замороженные ownership обеих сторон, уведомление через outbox и реальные game
actions для срока владения. Исправлены порядок блокировок, старые кнопки,
дубли после смены владельца, срок принятия до 00:00 UTC и сохранение expiry
без исключения, которое раньше откатывало обновление router-транзакции.
Точный kickoff объявляется после заявки/принятия при попадании в горизонт;
обнаруженное временное пересечение отклоняет заявку. История клуба/игрока
правильно помечает тип игры. Политика травм/билетов и рабочий прогресс 50%
[описаны явно](friendly-runtime.md), без объявления коэффициента решением пользователя.

Академия ограничена межсезоньем, список и лимит фиксируются одним intake по
club+season. Поздний upgrade не расширяет текущий набор; кнопки фиксируют сезон
или исходный ценовой уровень. Подписание бесплатно, numeric caps скрыты,
Person получает настоящий возрастной календарь и lifecycle receipts.
Неподписанные выпускники один раз выходят в общий пул при season.open.
Содержание пропорционально времени, история улучшений предотвращает пересчёт
прошлых счетов по новому уровню. Upgrade и ledger сохраняются атомарно.

Общая цепочка миграций: 0035 allocation → 0036 champions → 0037 friendly →
0038 academy → 0039 общие турнирные участники, frozen intakes и immutable history.
История результатов/жребия/выпусков защищена от переписывания, downgrade с такой
историей явно отклоняется. Новые БД не создаются.

## Границы

AND-119 остаётся открытой: автоматическое выравнивание нового midseason комплекта
с иной границей, а также ожидание поздно завершающихся совместимых комплектов
ещё не реализованы. Сейчас только полностью готовые совместимые сезоны образуют
когорту в момент транзакции; остальные идут отдельно. Это не заявляется полной
синхронизацией всей игры. [Точный контракт](cross-set-rollover.md).

Friendlies предлагаются внутри текущего season container. Pending-вызовы можно
отозвать, принятую игру пользователь не отменяет. Они не создаются автоматически.
50% практики и ставки академии — рабочие параметры прототипа для калибровки.
