# Дополнительные позиции · AND-108

Новые публичные и скаутские футболисты получают 1–3 освоенные позиции. Генерация
`player-positions-v1` использует стабильный person ID: 60% одна, 30% две, 10% три.
У вратарей только GK; одинаковых/чужих/неограниченных позиций нет. Начальные люди,
пенсионные замены бот-клубов и исторические матчевые snapshots не переписываются.
Переподготовки нет.

| Основная | Возможные дополнительные |
|---|---|
| GK | — |
| DC | DL, DR, DM |
| DL | DC, ML |
| DR | DC, MR |
| DM | DC, MC |
| MC | DM, ML, MR, AMC |
| ML | DL, MC, AML |
| MR | DR, MC, AMR |
| AMC | MC, FC, AML, AMR |
| AML | ML, AMC, FC |
| AMR | MR, AMC, FC |
| FC | AMC, AML, AMR |

Связи симметричны. Каждая дополнительная связана непосредственно с основной;
до двух разных позиций выбираются без повторов. Навыки/потолки остаются
индивидуальными, дополнительная позиция не копирует чужую роль с полной силой.

Сохранена действующая match policy: основная 100%, дополнительная 85%, чужая
полевая 60%. Lineup разрешает чужую полевую позицию с предупреждением; вратарские
ограничения сохраняются. В `/lineup` показаны все позиции и метки ↔85%/⚠️60%;
карточка, свободный рынок и аукцион тоже показывают полный список.

При равном качестве/возрасте цена за 2/3 позиции ×1.15/1.30, зарплата ×1.08/1.16.
Предложение и новый контракт фиксируют сумму, обучение её не меняет. Генерация
рынка и скаутов сохраняет позиции один раз; чтение/повторная подпись не меняют их.
Тренировка использует фактически назначенную позицию XI (или основную вне XI),
обрабатывает игрока один раз и не выдаёт несколько наград за универсальность.
