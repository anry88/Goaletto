# Портреты: текущая библиотека и история комбинатора

**Решение пользователя 2026-10-11:** после девяти сборок выбран банк цельных
иллюстрированных портретов. Экспорт 256px и 96px, отдельные мужские players/staff,
два цвета формы меняются локально; лицо не собирается из случайных черт.
Возрастные варианты и переход player→staff должны сохранять identity.
[Карьера персонала](staff-lifecycle.md). Текущий банк: [whole-v2](../assets/portraits/whole-v2/README.md),
1 000 футболистов и 80 сотрудников, [галерея](../assets/portraits/whole-v2/index.html).
[Возрастное расширение](portrait-lifecycle.md) содержит контракт и локальный выбор
цельных стадий одной внешности. Фактический объём — в его import-report.json;
игровое назначение в PostgreSQL ещё не реализовано. Небольшую похожесть лиц пользователь
допустил; appearance ID по-прежнему нельзя повторять между разными людьми.

## История пилотов

**Текущая проверка качества:** [новый эксперимент](portrait-feasibility.md).
Прежняя [растровая автосборка](portrait-raster-generator.md) отклонена пользователем визуально.
32 прозрачные детали, отдельные мужские банки, сохранённый рецепт, возрастные overlays
и два актуальных цвета клуба. PNG создаётся локально в Python без нейросетевого запроса.
Дальше описан прежний технический SVG-пилот; его IDs сохранены.

Иллюстрированный внешний вид прорабатывается отдельно в
[пробе Dugout v01](portrait-style-pilot.md). Согласование этой внешности предшествует
новым production-слоям; технический SVG-пилот ниже сохраняет прежние IDs.

Пилот: собственные SVG-компоненты на единой сетке 256×256, два отдельных банка.
AI-концепты используются только как ориентир; из них не вырезаются production-части.

Рецепт хранит schema_version, bank, seed, выбранные component IDs и палитру.
Одинаковый seed + bank + версия manifest даёт одинаковый рецепт во всех процессах.
Рецепт сохраняется у человека: повторная генерация не зависит от порядка случайных вызовов
матчевого движка. После обновления manifest старый рецепт продолжает рендериться.

## Взросление без смены личности

Базовые IDs/skin/hair и aging_profile закреплены за футболистом; возраст +1 за сезон
меняет только возрастные варианты/overlays, не перегенерирует все части. Кеш включает
age_stage и manifest version. 32–38 не означают обязательную седину/пожилое лицо.
Отдельный текстовый статус «Последний сезон» не выводится из портрета.
[Контракт](player-lifecycle.md), [иллюстрированная проба](portrait-style-pilot.md).
Это требование production-каталога; нынешний SVG-пилот не содержит age runtime.

## Банки

- players: молодые/взрослые действующие игроки 17–38, футболка, активные волосы,
  минимальные возрастные линии. Пилот демонстрирует визуальный диапазон, не реальный возраст.
- staff: сотрудники зрелого возраста, отдельные головы/глаза/причёски, седина,
  возрастные линии, очки, polo/tracksuit. Возраст задаёт сочетание, не просто серый цвет волос.

После согласования C пилот расширен: 5 форм лица, 4 глаза, 4 носа, 3 рта, 6 причёсок
и 3 варианта одежды в каждом банке; shared ears/neck и 3 варианта возрастных линий персонала.
Количество сочетаний не равно количеству убедительных уникальных людей:
совместимость и визуальное различие проверять отдельно.

## Слои и координаты

Порядок: background → torso → neck → ears → face → eyes → nose → mouth → age_details →
hair → accessories. Все части на общей 256×256 сетке с прозрачным фоном.
Глаза около y=117, центр лица x=128, нос y=133–150, рот y=163.
Масштаб головы и линии шеи должны совпадать во всех частях одного банка.
Локальные snippets используют placeholders {skin}, {skin_shadow}, {hair}, {kit},
{accent}, {ink}. Палитра валидируется как hex-цвет, filenames задаёт только manifest.

## Вывод

- SVG: runtime на стандартной библиотеке Python, без сетевого запроса.
- PNG: CairoSVG в инструменте просмотра; production PNG/cache adapter — отдельная задача.
- Разрешения: мастер 256, Telegram PNG 512; контроль читаемости 96.
- Не добавлять пользовательский текст/HTML в SVG, не разрешать пути вне manifest.
- В новом каталоге пока только мужские игроки/персонал. Происхождение/внешность не задают навыки.

CLI:
goaletto-portraits --seed example-1 --bank players --output work/example.svg

Галерея: assets/portraits/previews/index.html; три игрока и три сотрудника.
Для production-каталога довести иллюстрированные слои до выбранного C и проверить качество сочетаний.
