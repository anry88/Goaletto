# События живого матча · AND-91

Одно редактируемое табло и экран `/match` показывают футбольную минуту, счёт,
удары/попадания в створ и компактную ленту сохранённых событий. Поддержаны голы,
опасные удары (сейв, мимо, штанга), угловые, карточки, удаления (включая вторую
жёлтую), травмы, обычные/автоматические замены и применённые изменения тактики,
настроя и индивидуальных инструкций. Обычные перехваты не засоряют ленту.

Источник — MatchTick/MatchStage в PostgreSQL. Имена берутся из закреплённых
снапшотов, события дедуплицируются по ID и сортируются по футбольной минуте.
Показываются восемь последних важных эпизодов и четыре последних опасных момента/
угловых; полный архив остаётся в БД. HTML экранируется на границе отображения,
лента ограничена 1800 символами экранированного HTML без обрезания entities/строк.

Producer читает события в своей короткой транзакции и сохраняет готовую ленту
в outbox payload; transport по-прежнему работает после commit без SQL-транзакции.
Для бот-клубов без получателей не выполняются дополнительные запросы ленты.
Новые optional fields v1 совместимы со старым sender и старые payload по-прежнему
читаются: game_minute, commentary, shots, on_target. Lease/revision fencing,
дедупликация и редактирование одного табло не меняются.

Приём команды остаётся отдельным от её применения. Лента выводит только фактические
события применения, а блок статусов — «Принято», «Применено», «Отменено».
AND-90: на экране/в ответах нет номеров внутренних шагов, технических этапов или
дедлайна обработки. Сохранены футбольные лимиты замен/окон/тактики/инструкций.

Лента показывает последовательность действий и эпизодов, но не приписывает гол
конкретной инструкции. Для оценки влияния нужны сопоставимые серии симуляций;
одна игра не доказывает причинную связь. Коэффициенты и доменная симуляция не менялись.

Проверки: 402 unit/offline; mypy 87 source files; Ruff/format 221 files. Read-only
PostgreSQL проверка новой ленты и payload всех 25 настоящих матчей первого тура.
Destructive integration fixtures не запускались: мир, выбранные клубы, команды и
результаты текущего тура сохранены. Новый bot/worker подключаются после полного
завершения тура и обработки финальных уведомлений; текущие процессы до этого
обслуживают матчи прежней версией.
