# Small modular portrait pilot

players/ and staff/ are separate component banks. Shared neck/ears do not imply shared
age-specific heads, eyes or hair. Components are trusted repo-native SVG snippets
with palette placeholders, not images extracted from the generated concept sheets.

manifest.json fixes component IDs and layer order for schema version 1.
previews/ contains six assembled portraits, their recipes and a static HTML gallery.
Regenerate from the repo root: python scripts/render_portrait_preview.py.

This is an approval-stage technical pilot in the approved direction C palette, expanded with a few extra parts
after selection. Illustrated production quality is still a separate task.
