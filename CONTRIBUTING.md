# Работа с проектом

Проект закрыт по лицензии; доступ к репозиторию не предоставляет права на использование.
Задачи и порядок реализации ведутся в Linear. Перед изменением прочитайте AGENTS.md
и документы актуальных правил. Работайте небольшими изменениями в отдельной ветке.

Перед отправкой: ruff check ., ruff format --check ., mypy, pytest -q.
Для изменений очередей и миграций нужен PostgreSQL integration-прогон.
Миграции описывайте явно; уже опубликованные миграции не переписывайте.

Не добавляйте секреты, реальные пользовательские данные, дампы production или токены.
Описание изменения должно объяснять поведение и проверку. Прототипные визуальные материалы
не переводятся в production без согласования стиля.
